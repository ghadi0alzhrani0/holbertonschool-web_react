# Holberton Web React

This repository contains my TypeScript exercises for Holberton School.

The project is in the [TypeScript](TypeScript/) folder. It covers interfaces, classes, functions, namespaces and branded types.

## Getting started

Open a task folder and run:

```sh
npm install
npm run build
```

More details are in the [TypeScript README](TypeScript/README.md).
