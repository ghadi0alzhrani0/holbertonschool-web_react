# TypeScript Exercises

A collection of small exercises to practice TypeScript.

## Folders

| Folder | Tasks | Content |
| --- | --- | --- |
| task_0 | 0 | Students and an HTML table |
| task_1 | 1–4 | Teacher interfaces and a student class |
| task_2 | 5–7 | Employee types and teaching functions |
| task_3 | 8 | Type declarations for CRUD functions |
| task_4 | 9 | Subjects, namespaces and declaration merging |
| task_5 | 10 | Major and minor credits |

## Build

Run these commands inside the task folder you want to use:

```sh
npm install
npm run build
```

To check types:

```sh
npm run typecheck
```

For tasks 0, 1, 2, 3 and 5, start the development server with:

```sh
npm start
```

Task 4 uses the TypeScript compiler. After building, run:

```sh
node dist/subjects.js
```
